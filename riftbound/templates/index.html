Riftbound singles planner

Plan missing cards across decks. Review store printings before you buy.

Inventory snapshot mode. Prices and stock reflect the imported observation times; use the authorized importer to refresh. Import manually checked inventory or a CSV extracted from saved Riftbound category HTML below. This tool never accesses a cart or places orders.

1. Decks

Paste quantities or upload CSV. Separate decks with [Deck name]. Add an exact collector number with {SET-001}.

2. Collection (optional)

CSV headers: name,quantity,collector_number. Blank collector numbers count only toward requests without a collector constraint.

3. Store inventory snapshot

Use a CSV from the authorized importer, saved-page extractor, or manual inventory. Only names identified as Riftbound are eligible. You are responsible for checking the linked store evidence; the app cannot authenticate manual declarations. Blank price or stock stays unknown. Stock must be a numeric quantity, not an “in stock” guess.

Inventory CSV format

Required columns: name,game,verification,url,evidence_url,checked_at. Use Riftbound and manual; evidence URL should show the product belongs to Riftbound Singles. Timestamp must include timezone, e.g. 2026-01-01T12:00:00-05:00. Optional columns: collector_number,version,finish,condition,price_cad,stock. Prices must be CAD, without currency symbols. Use one row per distinct purchasable printing/variant. Never count the same stock twice.
